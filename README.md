# 批处理编译系统
gcc编译 参数控制 日志 调试 发布 优化
专业化的批处理编译系统，具备：

Release / Debug 两个分支（不同优化、安全策略）
单步模式（详细注释，方便理解和调试）
编译参数模块化（像搭积木一样组合最优参数）
安全、稳定、速度、兼容性优先
时间戳日志（增量附加，完整追溯编译过程）
日志文件可直接用记事本查看（利用特殊字符触发记事本的“日志模式”）


# 设计思路

参数模块化：把编译参数分成几类（优化、安全、链接库、平台等），方便组合
Release 分支：最大化优化，去符号、去编译器信息、可选 UPX 压缩
Debug 分支：保留调试信息，但仍去掉编译器版本标识，方便调试
日志系统：每次编译追加到 build_log.txt，带时间戳，利用 0xFEFF 或 0xFFFE BOM 触发记事本的日志模式（会自动滚动到末尾）


# 功能亮点


Release / Debug 分支

Release：最大化优化 + 安全处理 + 可选 UPX 压缩
Debug：保留调试信息，但去掉编译器版本标识



# 模块化参数

优化参数、平台参数、安全参数、链接库分开定义
方便组合、调整



# 日志系统

build_log.txt 采用 UTF-16 LE BOM（0xFEFF）触发记事本日志模式
每次编译追加记录（时间戳 + 模式 + 文件大小）
可完整追溯编译历史



# 安全性

Release 自动 strip + objcopy 去符号和 .comment 段
Debug 也去掉编译器版本标识



# 兼容性

适配 MinGW / MinGW-w64
Windows XP 及以上可运行
